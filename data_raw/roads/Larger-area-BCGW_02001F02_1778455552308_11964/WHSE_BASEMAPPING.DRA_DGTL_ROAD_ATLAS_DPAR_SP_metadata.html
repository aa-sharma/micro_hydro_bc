Digital Road Atlas (DRA) - Demographic Partially-Attributed Roads Digital Road Atlas Demographic Partially-Attributed Roads (DGTL ROAD ATLAS DPAR SP) provides partial information about roads in British Columbia. This data set represents the public data that is available for the Digital Road Atlas. Column Details
Column Name Short Name Data Type Data Precision Column Comments
DIGITAL_ROAD_ATLAS_LINE_ID DGTLRDTLSL NUMBER 10 DIGITAL ROAD ATLAS LINE ID is a unique numeric road segment identifier e.g. 453567.
FEATURE_TYPE FTRTP VARCHAR2 12 FEATURE TYPE is the feature type classification of the road, e.g. bridge, dam, ferry route, etc.
HIGHWAY_EXIT_NUMBER HGHWXTNMBR VARCHAR2 6 HIGHWAY EXIT NUMBER is a numeric or alpha-numeric identifier assigned to a road segment that allows egress from a segment designated as a highway, e.g. 5a.
HIGHWAY_ROUTE_NUMBER HGHWRTNMBR VARCHAR2 12 HIGHWAY ROUTE NUMBER is the designated Highways and Arterials numbers, delimited by a plus sign, e.g. 1+5+97.
SEGMENT_LENGTH_2D SGMNTLNGTH NUMBER 10 SEGMENT LENGTH 2D is the 2D road segment length in meters, e.g. 234.456.
SEGMENT_LENGTH_3D SGMNTLNGT1 NUMBER 10 SEGMENT LENGTH 3D is the 3D road segment length in meters, e.g. 123.456.
ROAD_NAME_ALIAS1 RDNMLS1 VARCHAR2 70 ROAD NAME ALIAS1 is the first full alias name, e.g. Trans-Canada Hwy E.
ROAD_NAME_ALIAS2 RDNMLS2 VARCHAR2 70 ROAD NAME ALIAS2 is the second full alias name, e.g. Hwy 1.
ROAD_NAME_ALIAS3 RDNMLS3 VARCHAR2 70 ROAD NAME ALIAS3 is the third full alias name, e.g Hwy 5.
ROAD_NAME_ALIAS4 RDNMLS4 VARCHAR2 70 ROAD NAME ALIAS4 is the fourth full alias name, e.g. Hwy 97.
ROAD_NAME_FULL RDNMFLL VARCHAR2 70 ROAD NAME FULL is the complete name for the road made up of the concatenation of the individual road name components, e.g. Elk Valley Hwy.
ROAD_SURFACE RDSRFC VARCHAR2 15 ROAD SURFACE is the road surface type, e.g boat, decommissioned, loose, overgrown, paved, rough, unknown.
ROAD_CLASS ROAD_CLASS VARCHAR2 12 ROAD CLASS is the navigational road classification, e.g alleyway, arterial, collector, etc.
NUMBER_OF_LANES NMBRFLNS NUMBER 2 NUMBER OF LANES is the total number of lanes of through traffic on both sides of the segment, e.g. 2.
DATA_CAPTURE_DATE DTCPTRDT DATE 7 DATA CAPTURE DATE is the Date of data capture in the format YYYYMMDD e.g. 20110623.
FEATURE_CODE FTRCD VARCHAR2 10 FEATURE CODE contains a value based on the Canadian Council of Surveys and Mapping''s (CCSM) system for classification of geographic features.
GEOMETRY GEOMETRY SDO_GEOMETRY 1 GEOMETRY is the column used to reference the spatial coordinates defining the feature.
OBJECTID OBJECTID NUMBER 38 OBJECTID is a required attribute of feature classes and object classes in a geodatabase.
SE_ANNO_CAD_DATA None BLOB 4000 SE_ANNO_CAD_DATA is a binary column used by spatial tools to store annotation, curve features and CAD data when using the SDO_GEOMETRY storage data type.
FEATURE_LENGTH_M FEAT_LEN NUMBER 19 FEATURE_LENGTH_M is the system calculated length or perimeter of a geometry in meters
